# genai_incidents attacker-methodology study

Replicable preliminary analysis. Everything in `out/` is produced by the scripts; nothing is hand-edited.

```
uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python fetch_data.py        # pin + fetch full JSON at the pip version's tag, clone rank-validation
.venv/bin/python s02_split.py         # ON-AI vs WITH-AI                                     -> out/split.json, out/s02_split.md
.venv/bin/python s01_overview.py      # conventions, corpus profile, rank-validation view     -> out/s01_overview.md (reads out/split.json)
.venv/bin/python s03_figures.py       # Figure 1                                             -> out/fig1_on_with.svg
.venv/bin/python s04_methodology.py   # entry point / target / medium / objective, reclassified  -> out/s04_methodology.md, out/dataset_pre.csv, out/dataset_post.csv
.venv/bin/python s05_techniques.py    # OWASP categories vs the vote and the hand labels     -> out/s05_techniques.md
```
`make all` runs the six in order (step 2 before step 1, because step 1's section C reads `out/split.json`). `draft.md` is the paper skeleton; its numbers come from `out/`.
Pins: `external/PINS.json`. Stdlib only beyond the `genai-incidents` package. `coded/relabels.json`: labels for the records the step-4 rules left unstated (two Claude coders + adjudicator, 2026-10-06; read by s04, not regenerated by `make`). `coded/review.json`: a review of every step-4 label (5,598; two independent Claude reviewers blind to the assignment step, an adjudicator for splits, a no-attacker consistency pass; 2026-10-07) with the corrections s04 applies to the post dataset and each label's review status (Tables 4.0b–4.0d); `coded/review_verdicts.json` keeps every reviewer's verdict, proposal and note, the adjudications and the model behind each batch, for a human check.

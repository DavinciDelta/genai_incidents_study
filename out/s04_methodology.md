# Step 4 — Entry point, target, AI medium and objective by keyword rule (what hand-coding must resolve)

Generated by `s04_methodology.py` (`make s04`); do not edit by hand. Keyword rules over the title + description + affected text give each ON-AI record an entry point and a target component, each WITH-AI record an AI medium and an attacker objective, and a read of corpus fields gives ON-AI a CVE/CWE flag; the frequency tables show the share within each disclosure channel and an `unstated` row that sizes the hand-coding workload. The last section lists where the rules are known to be wrong, with the records each defect moved.

Conventions, 95% CI, pooled rows and the glossary: `out/s01_overview.md` section 0.

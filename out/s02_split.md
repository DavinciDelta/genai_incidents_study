# Step 2 — ON-AI vs WITH-AI split

Generated by `s02_split.py` (`make s02`); do not edit by hand. Every record gets one population from deterministic rules over `attack_vector`, CVE/CWE presence, `category` and the title + description text. The deciding question is whose asset the AI system is:

- **ON-AI**: the AI system belongs to the victim and the adversary subverts it (it is the target or the vector).
- **WITH-AI**: the AI is the adversary's instrument against a conventional target.
- **BOTH**: both signals are present (for example a jailbreak whose output is then used against a third party).
- **UNRESOLVED**: adversary vocabulary is present but nothing says which population; these rows go to hand review.
- **NONE**: no adversary (a disclosure without exploitation, operator harm, or a model failure).

The *adversary frame* is ON-AI + WITH-AI + BOTH. How to read the tables: n is the denominator of the % column. It counts records unless the description says otherwise. % is rounded to one decimal. Where a table lists only the most frequent values, the remaining values are pooled in a last row, so each % column covers all of n. Where a column still does not sum to 100.0, a line under the table says why. 95% CI columns are percentile bootstrap intervals over records (2,000 resamples).

## Cross-check against incident-rank-validation human-adjudicated labels

An independent check that the split is recoverable: each population's records that also carry a human-adjudicated (gold) label from incident-rank-validation. *gold rows* is the number of such records. *out of scope* is the gold rows where the adjudicator judged that no taxonomy entry applies, with their share of that population's gold rows. *top adjudicated entries* lists the five most frequent gold entries with label counts. Only five are listed and a row can carry two labels, so those counts do not sum to gold rows minus out of scope. Use this to compare which entries each population lands on, not to estimate prevalence.

| population | gold rows | out of scope | top adjudicated entries |
|---|---|---|---|
| ON-AI | 158 | 23 (15%) | LLM04 22, LLM03 20, NEW-MTIE 17, LLM01 15, LLM05 12 |
| WITH-AI | 174 | 74 (43%) | LLM09 47, NEW-WLA 43, LLM02 2, LLM04 2, LLM05 2 |

| NONE | 756 | 330 (44%) | LLM09 64, LLM03 57, LLM05 55, LLM02 51, LLM06 48 |
